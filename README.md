## What we grow

| Project | What it is |
|---|---|
| [Mycel](https://github.com/MyCelium-GG/MyCel-Lib) | Shared core library behind every mod: config, utilities, events, networking, translations and more. One universal jar for Fabric, Forge and NeoForge. [![Release](https://jitpack.io/v/MyCelium-GG/MyCel-Lib.svg)](https://jitpack.io/#MyCelium-GG/MyCel-Lib) |
| AutoBlockRefiller | Empty hotbar slots refill automatically while you build. In development. |

## How it works

Small mods stay small because the boring infrastructure lives in Mycel.
One codebase builds for all three loaders, and every release is playtested
on dedicated servers before it ships.
